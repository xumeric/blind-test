# Blind test

Un blind test qui pioche dans ton Spotify : playlists, titres likés, un album, des artistes ou un style. Un extrait se lance, tu devines le titre (et l'artiste), puis tu écoutes le son en entier ou tu passes au suivant.

Page en ligne : https://xumeric.github.io/blind-test/

## Première connexion

1. Crée une app sur le [tableau de bord développeur Spotify](https://developer.spotify.com/dashboard).
2. Dans « Redirect URIs », ajoute `https://xumeric.github.io/blind-test/`.
3. Coche « Web API » et « Web Playback SDK ».
4. Ouvre la page et colle le Client ID de l'app.

Spotify exige un compte Premium pour le propriétaire de l'app. Les autres joueurs doivent être ajoutés dans « User Management » (5 maximum).
